# Security

Please report security problems privately, not in a public issue: open the repository's **Security** tab and choose **Report a vulnerability**. Describe what you found and how to reproduce it; a small crafted combat log that triggers it helps the most.

Only the latest release, the web app at [app.openlogs.gg](https://app.openlogs.gg) and the `development` branch receive fixes.

Examples of what counts: a combat log that makes OpenLogs run code, read files other than the log you opened, or send data anywhere; a weakness in the desktop app's content security policy; a problem in the release workflow or the published installers.
